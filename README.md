# Multithreaded Sorting Application · V-1-6

Хичээл: F.CSM302 Үйлдлийн систем 
Багийн дугаар: V-1-6
Сурах бичгийн харгалзах бүлэг: 4-р бүлэг - (Threads & Concurrency) 
Төслийн нэр: Multithreaded Sorting Application 
UI дүрслэл: Sorting animation

Бүхэл тоон жагсаалтыг хоёр хэсэгт хувааж, 2 sorting thread зэрэг эрэмбэлж, 1 merge thread нэгтгэх олон урсгалт эрэмбэлэлтийг browser дээр алхам алхмаар харуулна. Thread бүр (Web Worker) өөрийн хэсэг дээрх бодит үйлдлийг дүрслэлд илгээдэг тул дэлгэц зөвхөн чимэглэл биш, бодит ажиллагааг харуулна. Суулгах зүйлгүй: src/index.html-ийг нээхэд хангалттай.
