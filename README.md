## Зорилго

Энэхүү програм нь бүхэл тоон жагсаалтыг хоёр хэсэгт хувааж, хэсэг тус бүрийг хоёр Sorting Web Worker ашиглан зэрэг эрэмбэлнэ. Үүний дараа Merge Web Worker хоёр эрэмбэлэгдсэн хэсгийг нэгтгэнэ. Програм нь энэхүү олон урсгалт эрэмбэлэлтийн ажиллагааг browser дээр хөдөлгөөнт дүрслэлээр харуулна.
Worker бүр ажиллах явцдаа хийгдэж буй алхмуудаа postMessage ашиглан UI руу илгээх бөгөөд UI эдгээр мэдээллийг хүлээн авч, эрэмбэлэлтийн явцыг шууд дүрслэн харуулна. Ингэснээр хэрэглэгч эрэмбэлэлт хэрхэн явагдаж байгааг алхам бүрээр нь харах боломжтой.
Програмыг ажиллуулахын тулд нэмэлт build хийх эсвэл сервер асаах шаардлагагүй. src/index.html файлыг browser дээр нээхэд шууд ажиллана.

## Хэрхэн ажилладаг

![Урсгал](docs/image-2.png)
 
- **Хуваалт:** `half = ⌊n/2⌋`, сондгой үед 2-р хэсэг 1 элементээр том.
- **Sorting worker:** Insertion sort-ыг алхам бүрээр гүйцэтгэж `step` мессеж илгээнэ.
- **Merge worker:** `left[i] <= right[j]` нөхцөлөөр тогтвортой нэгтгэж, `leftIndex`/`rightIndex` илгээнэ.
- **Pause/Resume:** Worker алхам бүрийн өмнө `waitIfPaused()` шалгана.
- **Reset/`runId`:** Хуучин worker-ийн хоцорсон мессежийг үл тооно.
- **Blob URL:** Worker-ийг Blob URL-аар үүсгэдэг тул `file://` дээр ч ажиллана.

### Сурах бичгийн шаардлагатай тулгалт

| Шаардлага (Project 2) | Хэрэгжилт |
| :--- | :--- |
| Жагсаалтыг хоёр хэсэгт хуваах | `start()` дотор `half`-аар хуваана |
| Хоёр sorting thread | 2 Web Worker (`sortWorkerMain`) |
| Merging thread | 3-р Web Worker (`mergeWorkerMain`) |
| Thread бүрт өөрийн хэсгийг дамжуулах | `postMessage({type:"sort", workerId, values})` |
| Бүгд дууссаны дараа үр дүн гаргах | UI «Эцсийн үр дүн»-г гаргаж шалгана |
 
> **Хэрэгжилтийн ялгаа:** Ном глобал массивыг хуваалцахыг санал болгосон. Web Worker өгөгдөл хуваалцдаггүй тул хэсгийг `postMessage`-ээр дамжуулж, үр дүнг буцаан авна. Worker бүр зөвхөн өөрийн хэсэгтэй ажилладаг тул data race үүсэхгүй.
